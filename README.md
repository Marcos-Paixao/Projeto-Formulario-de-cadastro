# 📝 Formulário de Cadastro

Um formulário de cadastro moderno, responsivo e desenvolvido exclusivamente com **HTML5** e **CSS3**. Este projeto foca na estruturação semântica e na estilização avançada sem o uso de frameworks ou scripts externos.

---

## 🚀 Demonstração

Você pode visualizar o projeto online aqui: https://marcos-paixao.github.io/Projeto-Formulario-de-cadastro/

---

## 🛠️ Tecnologias Utilizadas

*   **HTML5:** Estruturação semântica e acessibilidade.
*   **CSS3:** Estilização, layout (Flexbox/Grid) e efeitos de transição.
*   **Google Fonts:** Tipografia personalizada.

---

## ✨ Funcionalidades

- [x] Design responsivo (funciona em mobile, tablet e desktop).
- [x] Feedback visual ao focar nos campos de entrada.
- [x] Validação básica nativa do HTML (campos obrigatórios e tipos de input).
- [x] Botões com efeito de hover.

## ⚙️ Como rodar o projeto localmente

1. Clone este repositório:
   ```bash
   git clone https://github.com/Marcos-Paixao/Projeto-Formulario-de-cadastro.git
   ```
2. Navegue até a pasta do projeto:
   ```bash
   cd Projeto-Formulario-de-cadastro
   ```
3. Abra o arquivo `index.html` diretamente no seu navegador ou utilize a extensão **Live Server** do VS Code.
